# お酒(赤ワイン/白ワイン)分類ニューラルネットワーク

[Chainerチュートリアル13章「ニューラルネットワークの基礎」](https://tutorials.chainer.org/ja/13_Basics_of_Neural_Networks.html)
で説明されている順伝播・誤差逆伝播・勾配降下法を、そのまま手で実装した学習用スクリプトです。
フレームワーク(Chainer/PyTorchなど)は使わず、NumPyだけで書いているので、
forward → loss → backward → update の一つ一つの式をそのまま自分のコードで追えます。

## セットアップ・実行方法

```bash
pip3 install numpy
python3 alcohol_classifier.py
```

実行すると、エポックが進むごとに損失(loss)が減っていく様子と、
最後にテストデータでの正解率が表示されます。

## コードとチュートリアルの対応

| `alcohol_classifier.py` | チュートリアル13章の説明 |
|---|---|
| `u1 = X.dot(W1) + b1` / `h1 = sigmoid(u1)` | 線形変換 → シグモイドによる非線形変換(順伝播) |
| 交差エントロピー誤差 `loss` | 分類問題の目的関数 |
| `dL_du2 = (y - t) / N` 以降の一連の式 | 連鎖律による誤差逆伝播(`dydh1` → `dh1du1` → `dLdu1` → `dLdw1` の流れと対応) |
| `W -= learning_rate * dL_dW` | 勾配降下法によるパラメータ更新 |

チュートリアル中の「年数・アルコール度数・色合い → 赤ワイン/白ワイン」という
説明用の例を、実際に動くデータ生成・学習・評価まで一通り実装したものです。
